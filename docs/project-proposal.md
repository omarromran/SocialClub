# Project Proposal

## Overview and problem statement

This project proposes a web-based social media platform where users can create profiles, share content, communicate, and control the visibility of their information. Many online communities combine these activities, but users need a simple, understandable platform with clear privacy controls. The project will provide a practical university Software Engineering implementation using PHP, MySQL, HTML, CSS, and vanilla JavaScript.

## Objectives

- Provide secure registration, login, and profile management.
- Allow users to share and interact with text, images, videos, and links.
- Support social relationships, personalized feeds, messaging, and notifications.
- Provide administrators with moderation and engagement tools.
- Demonstrate maintainable, secure, documented software development.

## Intended users

Registered users will manage profiles, relationships, content, privacy, and messages. Administrators will manage users, moderate content, control selected features, and review engagement reports.

## Main features

Registration and login; customizable profiles; multimedia posts; following or friend requests; likes, comments, and shares; privacy controls; private messaging; personalized feeds; notifications; and administration tools. Complex features such as messaging, notifications, moderation, and reporting are planned for later phases.

## Scope and limitations

The first phase establishes structure and planning only. Later phases will implement features incrementally. The initial deployment is intended for a local XAMPP environment, not production-scale hosting. External media storage, advanced recommendation algorithms, mobile applications, and third-party integrations are outside the initial scope.
